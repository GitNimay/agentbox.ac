What happened

Vibe Kanban's README carries the line "Vibe Kanban is sunsetting" above its screenshots, linking to a shutdown announcement. The announcement went up on 10 April 2026, and the reason given was that almost all users were on the free tier and no business model was found. The hosted side was switched off about a month later.

As of today the repository is not archived, it is Apache-2.0, and the last commit to its default branch was 19 September 2026. So the code is still there and still forkable. If a self-hosted board that nobody is patching is acceptable to you, you can keep running it — this is open source and that is a legitimate choice. The question is whether you want to be the one patching it.

What you are actually replacing

Three things, and different tools cover different ones:

  • The board. Tasks in columns, moving as the agents work.
  • Agent execution. Each task handed to a coding agent in its own isolated checkout.
  • It being a local web app. Runs on your machine, open in a browser tab, no native install.

Most alternatives give you the first two. The third is rarer than you would think, because nearly everything in this category is now a desktop app.

When to stay where you are, or go elsewhere

  • Keep running Vibe Kanban if it already does what you need and you are comfortable owning a fork. Apache-2.0, 28,377 stars, and the code does not stop working because the company did.
  • Pick Orca if community size is what makes you feel safe after being burned by a shutdown. It is the largest by two orders of magnitude.
  • Pick Emdash or Nimbalyst if you want a board in a maintained native app on Windows or Linux. Both ship one; our native build is macOS.
  • Pick Agentbox if you want the local-web-app shape back, want a board and an inbox rather than only a board, and want it free on the subscription you already pay for.

And the fair warning, since you have just been through this: we are three weeks old with 77 stars. The code is GPL-3.0 and runs entirely on your machine, so if we disappear you keep everything — but we are not going to pretend that longevity is a thing we have demonstrated.

Moving across

There is no import. Both tools drive the same agents on the same repositories, so moving means pointing the new one at the same folder and filing the tasks you still care about. Agentbox gives each task its own git worktree under .claude/worktrees/; nothing about your existing branches changes.
