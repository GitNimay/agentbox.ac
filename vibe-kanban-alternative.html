Written 16 October 2026, updated 17 October. Stars and last-commit dates from the GitHub API that day.

What happened

The README carries the line "Vibe Kanban is sunsetting", linking to the announcement. It went up on 10 April 2026. The reason given was that almost all users were on the free tier and no business model was found. The hosted side was switched off about a month later.

The repository is not archived, it is Apache-2.0, and its last commit was 19 September 2026.

Keeping it is legitimate

This is open source. The code did not stop working because the company did. If it already does what you need, you can run and fork it, and 28,377 stars means plenty of other people are in the same position.

The question is whether you want to be the one patching it when a coding agent changes its CLI. If the answer is no, the rest of this page is for you.

You are replacing three separate things

The board, with tasks in columns that move as agents work. The execution, with each task handed to an agent in its own isolated checkout. And it being a local web app, open in a browser tab with nothing to install.

Most alternatives cover the first two. The third is rarer than you would expect, because almost everything in this category is now a desktop app.

Agentbox, and the warning that goes with it

Every task gets its own git worktree, its own branch and its own agent. Finished work comes back as a row on a board or in an inbox, and you answer, approve or close it. It runs Claude Code and Codex on the plan you already pay for, with no server and no account.

You have just been burned by a project stopping, so: we are three weeks old with 77 stars, against the 28,377 you are leaving. We have not demonstrated longevity and saying otherwise would be insulting. What we can say is that it is GPL-3.0 and runs on your own machine, so if we disappear you keep a working copy and all your repositories are untouched.

Moving across

There is no import, and you do not need one. Both tools drive the same agents on the same repositories, so moving means pointing the new one at the same folder and filing the tasks you still care about.

Agentbox puts each task in .claude/worktrees/ on its own branch, so nothing about your existing branches changes. Run both on the same repo for a week and keep whichever you open first in the morning.
