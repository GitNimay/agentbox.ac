Is there a GUI for Claude Code?

There is no official one. Anthropic ships Claude Code as a terminal program, and every graphical front end is built by someone else. Ten exist. They differ in one thing that matters.

Written 16 October 2026, updated 17 October. Stars and licences read from the GitHub API that day.

What they differ on is what happens when an agent stops

Starting agents is easy in any of them. The problem arrives twenty minutes later.

You have five running. One finished. One is mid-thought. One has been sitting on a yes-or-no question since you went to make coffee. In a terminal all three look identical until you switch to the tab.

So the real question behind "is there a GUI for Claude Code" is narrower than it sounds. It is whether the thing can tell you which agent needs you. A prettier single-session window does not answer it.

Three shapes, and they suit different people

An editor plugin. Keeps you in VS Code or a JetBrains IDE. One agent at a time. Closest to how you already work.

A terminal that knows about agents. Tabs, status, notifications, still text underneath. cmux is this now, after moving from orchestration to being a Ghostty-based macOS terminal.

A desktop app that runs many agents. Each agent gets its own git worktree and the app becomes where you watch them. Most of the active projects are here.

Below three agents, the terminal is fine and an app is overhead. Above it, the app starts paying for itself.

Two that lists still recommend

Vibe Kanban is sunsetting. The notice sits above the screenshots in its own README and links to the announcement, posted 10 April 2026. Last commit 19 September 2026. Crystal is deprecated; its repository description now reads "Crystal is now Nimbalyst", and its last commit was 26 February 2026.

On Windows or Linux, the list is shorter

Several of the best-known options are macOS only. Conductor is Mac-only. cmux is a macOS terminal.

The native options elsewhere are Orca, Emdash and Nimbalyst.

Agentbox ships a macOS app. The same program runs in a browser on any platform with Node 22:

$ npx agentbox-app
Agentbox is running at http://127.0.0.1:51734/?k=9f3c2a
Press Ctrl-C to stop.

It listens only on 127.0.0.1, the key changes every run, and nothing is hosted. On Linux, installing from a checkout also puts agentbox on your path with a launcher entry. There is no Windows app, and we are not going to pretend otherwise.

When the terminal is still the right answer

Stay in it if you run one agent at a time. Stay in it if you live in tmux and your muscle memory is worth more than any window. Stay in it if you are on a remote box over ssh.

Claude Squad is a few hundred lines of tmux wrangling with no telemetry, and for some people that is the whole point. An Electron app is the wrong shape for them.

What Agentbox does

Every task gets its own git worktree, its own branch and its own agent. They run in parallel. When one finishes or gets stuck, its row comes back to you, and you answer, approve or close it the way you clear email. There is a board too.

It runs Claude Code and Codex locally on the subscription you already pay for. No server, no account, no API key.

Where it loses: it is three weeks old with 77 stars, the smallest project in the table. Orca has a community a thousand times the size. Conductor has a company, a team plan and cloud workspaces. If you want a native Windows build, three others ship one and we do not.
