Guide

Is there a GUI for Claude Code?

Yes, and Anthropic ships it. The Code tab in the Claude desktop app runs sessions in parallel, each optionally in its own git worktree, with an integrated terminal and a diff view, on macOS, Windows and a Linux beta. Twenty-one third-party front ends exist beside it, and the question this page answers is which of them is still worth running.

Written 16 October 2026, corrected 23 October against Anthropic's own documentation. Stars and licences come from the GitHub API on 17 October and have moved since, by 7.9% in Orca's case.

People go looking after they lose track of an agent

Somebody starts four agents, goes off to do something else, and comes back unable to tell which has finished, which is mid-thought, and which has been sitting on a yes-or-no question for twenty minutes.

The test is whether the interface says which agent needs an answer, and several of the options in the table below do not.

The four shapes of front end

The right shape changes completely between running one agent and running five.

An editor plugin

An editor plugin keeps everything inside VS Code or a JetBrains IDE, the only one of the four shapes with no new window to learn. It handles one agent at a time, because the editor does not know the others exist.

A terminal that knows about agents

This shape adds tabs, status indicators and notifications over the same text that was there before. cmux is the one in the table below now, having moved from orchestration to being a Ghostty-based macOS terminal.

A desktop app running many agents

Each agent gets its own git worktree, and the app itself becomes the place where all of them are watched. Most of the projects still alive sit in this shape, and they differ mainly in the form of the thing that reports an agent has stopped, which is a grid, a board, a list or an inbox.

A self-hosted web UI

A self-hosted web UI runs on a local machine or on a box somebody rents and opens in a browser, which makes it the only one of the four shapes that reaches a phone without a native app. claudecodeui is the biggest self-hosted web UI of the twenty-one.

Three of these tools are dead or pivoted

Vibe Kanban is sunsetting, and its README puts the notice above the screenshots and links to the announcement from 10 April 2026, with the last commit on 19 September. Crystal is deprecated, with a description that now reads "Crystal is now Nimbalyst", and cmux is no longer an orchestrator at all.

All three of them still appear on recommendation lists written this year, and the last commit date is what catches them.

Four questions separate these tools

The screenshots are the least useful part of every project page on the list.

The first question is whether the interface shows which agents are waiting without each one being opened, the second is whether it isolates each agent in its own worktree or lets them share a folder, the third is whether it runs on a Claude subscription or wants an API key, and the fourth is when it last got a commit.

$ gh repo view stablyai/orca --json stargazerCount,pushedAt,licenseInfo
{"stargazerCount":95206,"pushedAt":"2026-10-17T...","licenseInfo":{"spdxId":"MIT"}}

That one command answers the last of those four questions for any repository on the list, and the licence and star columns above come from it.

What a GUI does not fix

None of the twenty-one front ends fixes the three things below.

Reviewing the work. Five finished agents mean five diffs to read, and that reading is the slowest part of the whole loop. An app can put the diff on screen, but it cannot decide whether the change is right.

Writing the task. A vague instruction produces a vague branch, and running ten agents at once multiplies the vagueness.

The limits of a subscription plan. Ten agents that trip a rate limit trip it in every tool on the list, because no interface changes what a subscription tier allows.

Questions about getting a GUI

Does Claude Code have an official GUI?

Yes. The Code tab in the Claude desktop app, on macOS, Windows and a Linux beta, with a paid subscription. It runs several sessions at once from a sidebar, puts each in its own git worktree when Worktree is turned on, and carries an integrated terminal, a file editor and a diff view. The CLI also has claude agents, which groups sessions under Needs input, Working and Ready for review.

How do I install a Claude Code GUI?

Most are a normal download or a one-line npm command. Agentbox runs without being installed at all.

$ npx agentbox-app
Agentbox is running at http://127.0.0.1:51734/?k=9f3c2a
Press Ctrl-C to stop.

It listens only on 127.0.0.1, the key changes every run and nothing is hosted.

Is there a free and open-source option?

Most of the table is. MIT, Apache-2.0, AGPL-3.0 and GPL-3.0 are all represented, and the only closed-source entry is Conductor. Two of the projects are source-available, which is not the same as open source.

Is there one for Windows?

Yes, and the list is shorter than it looks because several well-known options are macOS only. Orca, Emdash, Nimbalyst, Nezha and harnss all ship Windows builds, according to their own READMEs.

Is there one for Linux?

The same five, plus the terminal UIs, plus anything that runs in a browser. Agentbox installs on Linux from a checkout and adds a launcher entry, and `npx agentbox-app` works anywhere Node 22 does.

Can I run one in a browser or on my phone?

claudecodeui is built for exactly that and is the largest of the self-hosted web UIs among the twenty-one. Superset has a native iOS app and Conductor has a mobile app on its $50 Pro plan.

Questions about the terminal

GUI or CLI, which should I use?

Below three agents, the terminal is fine and an app is overhead. Above three, the app starts paying for itself, because the cost it removes is the tab-checking rather than anything the machine does.

Is a GUI slower than the terminal?

No, because the agents wait on a model rather than on the interface. Three agents running together finished in 17.1 seconds against 16.4 for one alone, and the front end accounts for none of that. The timings and the method are here.

What about a TUI instead?

Claude Squad, ccmanager, devteam and grove are terminal interfaces rather than graphical ones, and the twenty-one includes them. They stay in one window, carry no Electron, and suit people who already live in tmux.

Can I use one over ssh?

A TUI works over ssh and a desktop app does not. For a remote box, a self-hosted web UI is the usual answer, because it needs only a forwarded port and a browser.

Questions about how they work

Do these use git worktrees?

The ones that run several agents at once nearly all do, because two agents in one folder overwrite each other. Making a worktree is one command, and the repository lists whatever a tool has created.

$ git worktree list
/Users/you/app              4a1c9f2 [main]
/Users/you/app/.claude/worktrees/w-7c21   8b31e07 [agentbox/w-7c21]

A stale worktree holds a branch and a lock file until it is removed, which is one more command.

Will it cost extra on top of my Claude plan?

Most run on an existing Claude Code or Codex subscription, and Conductor charges $50 a month for Pro. The thing to check is whether a tool asks for an API key, because that bills separately from the subscription.

Can it run Codex as well as Claude Code?

Some can. Agentbox runs Claude Code and Codex side by side on the same board, with neither of them as the default.

What happens to my repository?

Each task gets a worktree and a branch, to merge or delete when it is done. A local tool sends nothing anywhere and leaves the existing branches alone.

Every number came off the GitHub API

Every number in the table comes from the GitHub API on 17 October 2026, and the check is short enough for anybody to re-run.

for r in stablyai/orca manaflow-ai/cmux smtg-ai/claude-squad; do
  gh api repos/$r --jq '"\(.full_name) \(.stargazers_count) \(.pushed_at[0:10])"'
done

The platform and shape columns come from the README of every project on the list. Where a project calls itself source-available rather than open source, the table repeats that wording, because the distinction matters to the people who go looking for an open-source option.

Can I use one with a local model?

Some front ends allow pointing Claude Code at a different endpoint, which is a Claude Code setting rather than something the interface provides. Most of the tools assume the hosted model and say nothing either way, so the project's README is the place to look for it.

Will it keep working when Claude Code changes?

Every tool here drives the CLI, so one change to the CLI can break all of them at once. What protects against that is a commit in the last month, and four entries in the table above have not had one.

What happens to my shell setup, aliases and hooks?

A desktop app usually spawns its own shell, so a login-shell alias may be missing. Anything configured inside Claude Code travels with it, because the app runs the same binary as the command line.

What Agentbox does

Every task in Agentbox gets its own git worktree, its own branch and its own agent, and all of them run at the same time. When one finishes or gets stuck, its row comes back to the top of the inbox, to be answered, approved or closed. There is a board as well as the inbox, and the terminal and the diff are built in.

It runs Claude Code and Codex locally on an existing Claude or Codex subscription, with no server in the middle, no account and no API key.

Start with the CLI's own worktree support

The CLI's own worktree support costs five minutes and is enough for a lot of people.

Where Agentbox loses

Agentbox has 78 stars against Orca's 95,206 and is three weeks old. There is no native Windows build, where Orca, Emdash and Nimbalyst all ship one, and no mobile app, where Superset and Conductor both have one. And there is no company behind it.
